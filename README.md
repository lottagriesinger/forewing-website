# FIREWING — Energy Gummies Konzeptwebsite

Responsive Frontend-Website, inspiriert von den bereitgestellten FIREWING-Referenzbildern: dunkle cineastische Atmosphäre, rote Akzente, leuchtende Flügel-Gummis, kräftige Display-Schrift, Produktbereiche und ein responsives Layout.

## Dateien
- `index.html` – alle Bereiche der Website und Dialoge
- `style.css` – vollständige Gestaltung für Desktop, Tablet und Smartphone
- `script.js` – Produktdialoge, Tabs, Warenkorb, Mengenänderung, Newsletter-Demo und Navigation
- `assets/red-wing.jpg`, `assets/blue-wing.jpg`, `assets/yellow-wing.jpg` – gerenderte Flügel-Gummi-Visuals in drei Farbvarianten

## Start
1. ZIP entpacken.
2. Ordner in Visual Studio Code öffnen.
3. `index.html` im Browser öffnen oder in VS Code mit **Live Server** starten.

Es ist kein npm-/Build-Schritt nötig. Google Fonts laden bei Internetverbindung; System-Fallbacks werden verwendet, wenn offline.

## Funktionen
- Desktop-Navigation und mobile Navigation
- Hero-Bereich, Produktstory, Vorteile, Sortenübersicht, Inhaltsstoffe/Nährwerttabelle, Story/Community und Footer
- Produktdetail-Dialog mit Übersicht, Inhaltsstoffen und Nährwerten
- Warenkorb mit Produktmengen, Zwischensumme und Demo-Checkout-Hinweis
- Responsive Layout mit mobil optimierten Karten, Menü, Dialog und Warenkorb

## Wichtige Hinweise
Diese Website ist ein Frontend-Konzept, kein fertiger Shop. Produktnamen, Zutaten, Nährwerte, Koffein- und Vitaminangaben sowie Packungsgröße und Preise sind **unbestätigte Demo-Angaben**. Sie müssen vor Veröffentlichung durch echte, fachlich geprüfte Produktdaten ersetzt werden. Allergene und rechtliche Pflichtangaben müssen ebenfalls ergänzt werden. Checkout, Zahlung, Versand, Bestellung, Newsletter-Versand und Datenspeicherung sind nicht mit einem Backend verbunden. Das Impressum und die weiteren rechtlichen Links sind Platzhalter.
